核心功能

注册与签到分离，控制台为主、图形界面可选，开箱即用。

人脸注册 · 多照片

上传静态照片 + 输入姓名即可注册。同一人可登记 2~5 张照片（戴/不戴眼镜、不同光线），识别时取最接近的一张——这是提升真实场景识别率最有效的办法。支持中文路径与原名显示。

摄像头实时签到

调用本地摄像头实时画面，逐帧检测人脸并与特征库比对。识别成功自动签到并写入 CSV，画面实时标注姓名与置信距离。

防重复签到

冷却期：签到成功后 60 秒内同一学生不再重复签到，画面标记「冷却中 · 剩余秒数」；每日去重：同一天只签到一次，程序重启后读取当天 CSV 继续生效，双重保险。

应到名单 · 打勾 · 缺勤名单

默认以特征库全部学生为应到名单，也可用 --roster 名单.txt 指定本次课堂名单。画面右侧名单侧栏识别到本人立刻打 ✅；结束时自动列出没来的人，并生成逐人标记「已到 / 缺勤」的出勤报告 CSV。名单里有人未注册人脸会提前提示。

CSV 签到记录

每天一个 CSV 文件，三列：学生姓名 / 签到时间 / 是否签到成功。utf-8-sig 编码，Excel 双击打开中文不乱码。

四态考勤 · 迟到与请假

不只是「来了/没来」：超过上课时间 + 宽限自动记迟到，--leave 王五 登记请假，报告逐人标记 已到 / 迟到 / 请假 / 缺勤。支持同一天多节课（-S 第1节），去重互不影响。

出勤统计 · 环境自检

stats.py 跨课次汇总每人的出勤率与迟到次数并导出 CSV；doctor.py 一键自检依赖、模型、摄像头、字体与目录权限，换机器也能快速定位问题。

未知人员标记

未匹配特征库的人脸画红色框标记「未知人员」，控制台限流提示，但不写入签到表——避免无效记录刷屏。

控制台 + 可选 GUI

简易控制台菜单开箱即用；另附 tkinter 图形界面：注册对话框 + 摄像头画面内嵌窗口，逻辑与控制台完全共用同一引擎。

工作流程

注册阶段处理静态图片，签到阶段处理摄像头实时画面，两阶段共用特征库。

注册阶段 · 静态图片
  1. 上传照片支持中文路径（jpeg / png / bmp）
  2. YOLO-Face 检测yolov8n-face.pt · 约 6MB · 多张人脸自动选最大
  3. YuNet 关键点对齐5 点仿射变换，抗角度差异
  4. SFace 提取 128 维特征OpenCV DNN 推理 · 约 37MB
  5. 存入特征库data/embeddings/姓名.npy
特征库
签到阶段 · 摄像头实时
  1. 摄像头取帧自动曝光预热 5 帧，画面更稳
  2. YOLO-Face 检测逐帧检测画面中的所有人脸
  3. 提取特征并比对欧氏距离 ≤ 阈值 → 识别成功
  4. 自动签到 + 打勾侧栏名单立刻 ✅，冷却 60s 防重复
  5. 输出缺勤名单对照应到名单 → 没来的人 + 出勤报告
距离越近越是同一个人：≤ 1.0 判定为本人签到，> 1.0 标记未知人员；阈值可在 config.py 或 --tolerance 参数中调整。

快速开始

三步跑起来。首次运行会自动下载 3 个模型文件（共约 43MB，含备用地址）。

Windows · Python 3.10+
$ pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu # CPU 版 PyTorch（可选，走镜像则省略）
$ pip install -r requirements.txt # 国内加速：加 -i https://pypi.tuna.tsinghua.edu.cn/simple
$ python register.py -i 照片.jpg -n 张三 # 人脸注册：上传照片录入特征库
$ python checkin.py # 摄像头实时签到（应到 = 全部已注册学生）
$ python checkin.py --roster 名单.txt -S 第1节 --leave 王五 # 名单 + 节次 + 请假，按 q 退出
✅ [签到成功] 张三（2026-11-11 10:23:45） ⚠️ 检测到未知人员（不在特征库中） 出勤：应到 30 人 | 实到 26 人 | 请假 2 人 | 缺勤 2 人 ⏰ 迟到（3）：孙八、周九、吴十 ❌ 未到（2）：赵六、钱七
$ python stats.py --roster 名单.txt # 汇总本学期出勤率 → 出勤统计.csv

无摄像头也能演示：python scripts/make_demo_video.py 照片.jpg demo.mp4 然后 python checkin.py --source demo.mp4 --no-window。图形界面运行 python gui.py，控制台菜单运行 python main.py。

常见问题

为什么不用常见的 face_recognition（dlib）库？

dlib 在 Windows 上没有官方预编译包，需要安装 CMake + Visual Studio 编译工具链才能从源码编译，对课程作业不够「开箱即用」。本项目改用 OpenCV 自带的 DNN 模块运行 SFace 模型，纯 pip 安装即可使用。

识别不准确 / 换了样子认不出怎么办？

先多登记几张照片——这是最有效的一招。实测同一人「戴眼镜」与「不戴眼镜」两张照片的特征距离可达 1.33，和「不同的人」几乎一样远，单一登记必然认不出；把两张都登记后，签到取最接近的一张即可解决：
python register.py -i 戴眼镜.jpg -i 不戴眼镜.jpg -n 张三
其次：注册照片要光线充足、正面无遮挡；正对摄像头、避免侧脸与逆光；必要时调整 MATCH_TOLERANCE 或运行时用 --tolerance。

没有摄像头怎么演示？

把注册照片生成演示视频：python scripts/make_demo_video.py 照片.jpg demo.mp4，然后 python checkin.py --source demo.mp4 --no-window 即可完整演示签到流程。

模型下载失败 / 网络不好？

每个模型都有 2~3 个备用下载地址自动切换；也可手动下载放到 models/ 目录（地址见 config.py）。YOLO 模型缺失时检测自动回退 OpenCV Haar 级联（精度略低）。

同一学生一天能签到几次？

同一天只签到一次：签到后进入 60 秒冷却期（画面标记「冷却中 · 剩余秒数」），冷却结束后当天内不再重复签到；程序重启后读取当天 CSV 继续生效。冷却时长可在 config.py 的 COOLDOWN_SECONDS 调整。

一天有两节课，同一个学生能签两次吗？

可以。用 --session 第1节 / --session 第2节 区分节次，签到记录分文件存放，每日去重也按节次独立计算。不指定节次时退化为「一天一签」。出勤统计会把每个节次算作一次课。

迟到和请假怎么记录？

迟到：签到时间晚于「上课时间 + 迟到宽限」（默认 08:00 + 10 分钟）自动判定，可用 --start 13:30 临时指定上课时间，或在 config.py 修改 CLASS_START_TIME / LATE_GRACE_MINUTES。请假：--leave 王五（可重复使用），或在名单 CSV 里给该学生标注「请假」。

缺勤名单是怎么算出来的？

以「应到名单」为基准逐个比对当天签到记录：应到名单默认是特征库里所有已注册学生，也可以用 --roster 名单.txt 指定本次课堂名单（每行一个姓名，或 Excel 导出的 CSV 第一列）。签到结束时控制台打印缺勤名单，同时生成 attendance_YYYY-MM-DD_report.csv，每人一行标记「已到 / 缺勤」。不接摄像头也能用 python main.py 菜单的「4. 出勤报告」重新统计。
